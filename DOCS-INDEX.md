## Правила ведения

- **README.md** — единственное место пользовательских инструкций; не дублировать их в других файлах.
- **ARCHITECTURE.md** — обновляется при каждом дизайн-решении уровня «почему так, а не иначе».
- **CHANGELOG.md** — пополняется при закрытии спринта и при значимых работах по обслуживанию репозитория.
- **CLAUDE.md** — только то, что нужно ИИ-разработчику в работе: команды, ловушки, запреты; без пересказа README.
